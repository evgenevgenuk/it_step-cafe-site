Практичний екзамен: Web Core
HTML/CSS (60 хв)
Курс «Web Core: HTML/CSS», Час: 60 хвилин.
Завдання: сайт кав'ярні з двох сторінок
Створіть index.html , booking.html і один спільний styles.css . Зображення —
будь-які на ваш смак.
Сторінка index.html
Шапка з назвою кав'ярні та навігацією (три посилання: Меню, Бронювання,
Контакти).
Секція «Меню»: три картки страв. Кожна картка — figure із зображенням і
figcaption , заголовок h3 і короткий опис.
Секція «Години роботи»: таблиця з заголовками стовпців і щонайменше
трьома рядками (наприклад, пн–пт, субота, неділя).
Footer з адресою.
Сторінка booking.html
Та сама шапка й навігація, що й на головній.
Форма бронювання: ім'я ( text ), e-mail ( email ), кількість гостей ( select ),
коментар ( textarea ), кнопка. До кожного поля є label , ім'я та e-mail
обов'язкові ( required ).
Той самий footer.
Вимоги до стилів
Один styles.css для обох сторінок через <link, без style="" в HTML.
Навігація в рядок через Flexbox, стани :hover і :focus-visible .
Картки меню в сітці Grid із gap .
На екрані до 600px: картки в одну колонку, навігація вертикальна,
горизонтальної прокрутки немає. Перевірте в режимі пристрою DevTools.
